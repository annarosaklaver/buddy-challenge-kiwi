# Kiwi Buddy Challenge LING4136
This is a repository for the buddy challenge assignment of LING4136 at UiO, group kiwi.
---
## OG data and scripts
Contains the original script and data used in the selected paper (Hostetter & Bahl, 2023). This data and analysis code are available at https://osf.io/57cdw/?view_only=dd7a46754c274608a896549a2f38168e.
- `AGI Analyses revision.R`
- `AGI Study 2 data.csv`
- `AGI Study 1 data.csv`
---
## Analytical Reproduction
Contains the script used to assess the analytical reproducibility of Study 1 from the selected paper (Hostetter & Bahl, 2023) and the data. 
- `reproduction_AGI_study_1_data.csv`: contains the data for study 1 reproduction. 
- `study_1_reproduction.qmd`: cleans data; resolves inconsistent coding; bins categories; identified duplicates;
---
## Working data and scripts
Contains the revised version of the original script used to assess the computational reproducibility of Study 1 from the selected paper (Hostetter & Bahl, 2023) and the corresponding data. The original script was edited to enable reproducibility. Edits have been commented in the code. 
- `AGI_Analyses_revision.R`: revised script used for computational reproducibility assessment, including author comments of changes made. 
- `AGI_Study_2_data.csv`: study 2 data was not used
- `AGI_Study_1_data.csv`: Contains the data used
